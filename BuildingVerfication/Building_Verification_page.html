Project Overview

I developed a building-verification workflow to automate the classification and validation of residential building records. The workflow evaluates multiple housing and accessory dwelling unit fields, then creates a standardized summary in the Verified_Buildings field.

The process was designed to reduce repetitive manual editing, improve attribute consistency, and support quality assurance and quality control.

ArcGIS Pro ModelBuilder Python ArcPy Field Calculator QA/QC

Problem

Residential building information was stored across several attribute fields, including:

  • Single-family attached buildings
  • Single-family detached buildings
  • Two-to-four-unit residential buildings
  • Five-or-more-unit residential buildings
  • Mobile homes
  • Detached, attached, and repurposed ADUs
  • Junior accessory dwelling units

Manually reviewing every field and entering a combined value was time-consuming and could introduce inconsistent formatting or missed records.

Python Logic

The Python function checks each building field, adds populated classifications to a list, and joins the results into a standardized comma-separated value. The workflow supports building types such as SFA, SFD, M2_4, M5PLUS, MOBILE, ADU_D, ADU_A, ADU_R, and JADU. 

def Verified_Buildings(
    SFA,
    SFD,
    M2_4,
    M5PLUS,
    MOBILE,
    ADU_D,
    ADU_A,
    ADU_R,
    JADU,
    current_value
):
    def has_value(value):
        return value not in (None, "", 0)

    parts = []

    if has_value(SFA):
        parts.append("SFA," + str(int(SFA)))

    if has_value(SFD):
        parts.append("SFD," + str(int(SFD)))

    if has_value(ADU_D):
        parts.append("ADU_D," + str(int(ADU_D)))

    if has_value(JADU):
        parts.append("JADU," + str(int(JADU)))

    if not parts:
        return current_value

    return ",".join(parts)
